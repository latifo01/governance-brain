# Vault conventions

- `10_Sources` contains faithful evidence notes assembled from normalized Markdown.
- `20_Concepts`, `30_Domains` and `40_Rules` contain derived knowledge.
- `50_Questionnaires` contains bilingual, evidence-backed questions.
- `60_Maps` provides navigation without introducing new claims.
- `90_Audit` contains review reports and unresolved quality findings.
- `VERIFIED`, `PARTIAL`, `UNCERTAIN` and `CONFLICT` are explicit knowledge states.
- Every derived claim must point to a native source locator.
