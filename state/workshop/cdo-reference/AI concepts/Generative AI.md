**Generative AI (GenAI)** is a branch of artificial intelligence that can create **new, original content** —such as text, images, music, video, or code — based on human prompts.
### Key Aspects:
* **How it works:** It uses deep learning models (like Transformers or GANs) trained on vast datasets to learn underlying patterns, structures, and relationships in data. It then uses this knowledge to predict and generate plausible new outputs.
* **How it differs from traditional AI:** While traditional AI focuses on analyzing, recognizing, or classifying existing data (e.g., detecting spam or recommending a movie), Generative AI focuses on *creation*.
* **Common Examples:** 
  * **Text:** ChatGPT, Claude (writing essays, answering questions, summarizing)
  * **Images:** Midjourney, DALL-E, Stable Diffusion (creating visual art from text)
  * **Code:** GitHub Copilot (generating and debugging programming code)
