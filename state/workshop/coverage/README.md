# Governance coverage register

The file coverage-register.json is the programme-level backlog for the fifteen
governance pillars in ROADMAP.md. It records readiness, not regulatory
compliance. Update it only from reviewed lot evidence and keep the allowed
states stable:

- SOURCE_GAP
- EVIDENCE_READY
- PROPOSAL_READY
- HUMAN_REVIEW
- APPROVED
- COMPLETE

COMPLETE requires all ten Definition of Done checks in ROADMAP.md. Candidate
domain IDs remain proposals until a taxonomy review activates a Domain Pack.
