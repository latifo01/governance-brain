# Questionnaire Canvas

manifest records a content hash and filename without retaining a machine path.

Markdown questions.

Canvas nodes are not evidence, approval, or canonical question records. Proposed
Canvas files under questionnaire lots are derived review views. After an
approved Markdown integration, regenerate the release view from canonical IDs
and dependencies.
