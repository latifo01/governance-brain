# Third-party AI assurance and shared responsibility

## Purpose

Determine whether external AI dependencies have an accountable control and
evidence boundary that can be tested during normal operation and incidents.

## Guidance

Answer “yes” only when the project records the provider boundary and residual
gaps, assigns responsibilities contractually where appropriate, obtains
proportionate assurance evidence, monitors material changes and tests incident,
escalation, exit or rollback arrangements.
