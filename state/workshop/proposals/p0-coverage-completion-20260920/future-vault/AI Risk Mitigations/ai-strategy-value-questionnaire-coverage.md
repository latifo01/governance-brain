# AI strategy value — questionnaire coverage

## Summary

Questionnaire coverage should establish purpose, ownership, affected people, system scope and lifecycle decisions before asking detailed control questions.

## Applicability

This candidate is a governance coverage aid. It applies only when the organisation has an AI system, a defined purpose and a proportionate decision process; it does not collect project answers.

## Governance considerations

Use existing common-core questions first, then conditional modules for AI Act, data protection, assurance and security. Keep one question per intent and preserve stable topics.

## Evidence to retain

Question registry entries, dependency graph, evidence request mapping and review record.

## Limits

Questionnaires publish prompts, not answers or scores; coverage does not imply that a project is compliant.
