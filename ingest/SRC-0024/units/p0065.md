> 4.1.1.3 Analyse de code pour la détection automatisée de vulnérabilités 
> La détection automatique des vulnérabilités au sein même du code des systèmes 
> d’intelligence artificielle (IA) constitue un enjeu majeur de la cybersécurité 
> contemporaine. Les outils classiques de sécurité logicielle, comme les outils 
> d’analyse de code source ou Static Application Security Testing 30 (SAST) et le 
> Dynamic Application Security Testing31 (DAST), ont démontré leur efficacité dans le 
> domaine des applications traditionnelles.  
> Néanmoins, les systèmes d’IA introduisent des spécificités techniques et 
> méthodologiques qui nécessitent une adaptation de ces approches. Les modèles 
> d’apprentissage automatique, par leur dépendance aux données, aux paramètres 
> d’entraînement et à l’environ nement d’exécution ou au comportement atypique 
> d'un utilisateur malveillant  exposent de nouvelles surfaces d’attaque, telles que 
> l’empoisonnement de données, les attaques adversari elles ou encore les fuites 
> d’informations issues du modèle. Dans cette perspective, il convient de compléter
