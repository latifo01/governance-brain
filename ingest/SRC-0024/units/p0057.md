> 3.4.1 Les techniques cryptographiques 
> Chiffrement authentifié  : le chiffrement permet d’assurer la confidentialité des 
> données, mais également leur intégrité (authenticité). Une modification des 
> données chiffrées par un attaquant, ou l’absence de fourniture de données 
> d’authentification supplémentaires, engendrera une erreur au moment du 
> chiffrement. Le chiffrement authentifié standardisé le plus utilisé est AES GCM 18 
> (GCM - Galois Counter Mode  qui fournit le tag d’authentification). La taille d’un 
> chiffré AES GCM est égal à la taille du clair + 28 octets (12 pour le nonce19, 16 pour le 
> tag).  AES XTS20, généralement utilisé pour chiffrer les disques, n’est pas authentifié ; 
> il fournit pour seule garantie que si un chiffré a été modifié, les données déchiffrées 
> seront illisibles.
