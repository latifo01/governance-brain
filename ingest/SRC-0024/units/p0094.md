> 5.2.3.1.2 Attaque par code malveillant 
> CONSTRUCTION DU MODELE / 
> ADAPTATION D’UN MODELE 
> EXISTANT 
> ATTAQUE PAR CODE 
> MALVEILLANT PREDICTIVE & GENERATIVE 
> Présentation générique : 
> Manipuler la logique de prise de décision du modèle en modifiant les poids, en ajoutant du code malveillant dans les scripts 
> associés ou en altérant les règles existantes. Introduire des fonctionnalités malveillantes dans le modèle pendant le processus 
> d'apprentissage ou de réglage fin (fine-tuning). 
> Descriptif du scénario :  
> Après avoir accédé au modèle (ex : backdoor), l’attaquant modifie les poids du modèle pour influencer son comportement, ou 
> insère des instructions malveillantes dans le code qui gère le modèle ou dans les données qu'il traite. Ces instructions peuvent 
> être dissimulées dans des fragments de scripts, dans des jeux de données d'entraînement ou diffusé via un modèle pré -
> packagé sur une plateforme publique. Une fois infecté, le modèle peut générer du contenu incorrect et être détourné de son 
> usage initial, introduire des vulnérabilités dans le code qu'il produit ou fournir des informations sensibles à un attaquant.
