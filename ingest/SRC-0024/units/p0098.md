> •En décembre 2022, le projet PyTorch a subi une attaque ciblant sa chaîne de déploiement. Un paquet externe appelé torchtriton , utilisé 
> dans les versions de test (nightly), a été remplacé sur PyPI par une version malveillante. Ce fichier, téléchargé automatiquement lors de 
> l’installation, contenait du code qui exfiltrait des informations sensibles (clés SSH, variables d’environnement) via des req uêtes DNS. 
> L’attaque reposait sur l’absence de vérification d’intégrité du paquet. Cet incident illustre un cas typique de substitution de composant IA 
> en phase de déploiement, équivalent à un remplacement de modèle par un artefact compromis.
