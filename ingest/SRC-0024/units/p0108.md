> 5.2.6.3.1 Prompt injection - Extraction des données 
> VOL DES DONNEES PROMPT INJECTION – EXTRACTION DES DONNEES GENERATIVE 
> Présentation générique : 
> Ce scénario est une forme spécifique de prompt injection où l'objectif principal est d'extraire des informations sensibles ou  
> confidentielles à partir d'un modèle de langage (LLM). Dans ce type d'attaque, l'attaquant utilise des prompts soigneusement 
> conçus pour manipuler le modèle afin qu'il divulgue des données qu'il ne devrait pas révéler. 
> Descriptif du scénario :  
> L’attaquant utilise l’interface standard du LLM (chat, API REST, intégration RAG) pour injecter des prompts malicieux sans 
> nécessiter d’accès privilégiés. Son objectif est d’inciter le modèle à divulguer des informations sensibles issues de son jeu  
> d’entraînement, d'une base de connaissances externe ou de sessions utilisateurs actives. L'attaque s'appuie sur des 
> formulations habiles ou des techniques de dissimulation pour contourner les mesures de filtrage et ainsi exfiltrer les données 
> du SIA. Ces données peuvent être présentes dans le modèle de fondation, le fine-tuning, le méta-prompt ou les systèmes avec 
> qui le modèle communique (RAG, BDD, sharepoint…).
