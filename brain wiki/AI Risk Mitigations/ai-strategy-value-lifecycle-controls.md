# AI strategy value — lifecycle controls

## Summary

Strategy value is maintained through lifecycle controls that trigger reassessment when purpose, data, model, supplier or operating context changes.

## Applicability

This candidate is a governance coverage aid. It applies only when the organisation has an AI system, a defined purpose and a proportionate decision process; it does not collect project answers.

## Governance considerations

Define launch, change, rollback, restriction and retirement gates. Require documentation updates and a recorded reassessment for material changes.

## Evidence to retain

Lifecycle decision log, change record, reassessment record, release and retirement criteria.

## Limits

Framework guidance is contextual; thresholds and review cadence require local decisions.
