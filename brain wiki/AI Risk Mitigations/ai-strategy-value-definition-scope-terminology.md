# AI strategy value — definition and scope

## Summary

The strategy-value record connects an AI system to an intended purpose, expected organisational value, operating context and explicit boundaries. It distinguishes a value hypothesis from a performance claim or a legal conclusion.

## Applicability

This candidate is a governance coverage aid. It applies only when the organisation has an AI system, a defined purpose and a proportionate decision process; it does not collect project answers.

## Governance considerations

Record the intended purpose, target users, decision affected, expected benefit, excluded uses and success conditions. Keep value assumptions separate from risk and compliance conclusions.

## Evidence to retain

Purpose record, scope statement, value hypothesis, excluded-use record and approval history.

## Limits

Framework evidence supports governance practice; it does not establish a universal obligation or business outcome.
