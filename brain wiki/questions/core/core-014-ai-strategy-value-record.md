# AI strategy value record

## Purpose

Établir la base commune avant les questions détaillées de risque et de conformité.

## Guidance

Documenter la finalité, les utilisateurs, les décisions affectées, la valeur attendue, les limites et l’approbation ; ne pas confondre cette preuve avec un résultat économique réalisé.
