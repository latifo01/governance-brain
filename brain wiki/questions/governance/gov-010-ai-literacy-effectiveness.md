# AI literacy effectiveness and change triggers

## Purpose

Check that AI literacy is evidenced through role-appropriate competence and maintained when the system or operating context changes.

## Guidance

Answer "yes" only when the project defines role expectations, provides suitable materials, records access or completion and uses an assessment, observation, feedback or other proportionate evidence of competence. The project should also identify triggers for updating guidance when roles, users, purpose, data, tools or system behaviour change.
