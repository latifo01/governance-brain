# Governance Brain

Bienvenue dans le Wiki de Governance Brain. Ce Wiki sert de point d'entrée vers
la documentation versionnée du dépôt.

Governance Brain construit une base Markdown de connaissances revues, un
catalogue bilingue de questions, une recherche locale par sections et des
paquets de contexte cités. Obsidian organise la navigation humaine ; les preuves
et leur revue déterminent l'éligibilité du contexte utilisé par les agents.
